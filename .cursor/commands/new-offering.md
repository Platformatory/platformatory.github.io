# New offering

Create or rewrite a Platformatory offering landing page.

1. Read and follow `.cursor/skills/platformatory-content/SKILL.md` and `templates.md`.
2. Mirror frontmatter shape from a peer in `_offerings/` (prefer `streaming.md` or `managed-services.md`).
3. Write `_offerings/<kebab-slug>.md`. Permalink will be `/<slug>/`.
4. Required voice: concrete headline + lede; pillars/panels with one job each; no hero card clutter.
5. Include SEO `description`, primary CTA (default `/company#contact`), optional secondary CTA.
6. Reuse existing stack logos under `images/v2/expertise/` or `images/v2/partners/` when possible.
7. Do not wire consulting/services index links unless the user asks.

User context (if any) follows this command.
