# New team member

Add a Platformatory team member.

1. Read and follow `.cursor/skills/platformatory-content/SKILL.md` and `templates.md`.
2. Create `_team/<slug>.md` with `title`, `image`, `jobtitle`, `linkedinurl`, `weight`, `layout: team`, `draft: false`.
3. Place the headshot in `images/team/` (or reuse an existing path the user provides).
4. If they should appear on `/company/`, add a matching entry under the Leadership team `features` in `company.md`.
5. Mirror job-title register from peers (`_team/pavan.md`, `_team/ashwin.md`, etc.).

User context (if any) follows this command.
